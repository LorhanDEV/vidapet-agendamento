# VidaPet: Sistema de Agendamento da Clínica Veterinária

**Aluno:** Lorhan Messias
**Disciplina:** Projeto de Bloco: Desenvolvimento Back-End [26E4_5]
**Entrega:** TP1
**Trilha:** Java (JDK 21 LTS + IntelliJ IDEA Community)

## Estrutura

- `docs/`: documento de requisitos, diagrama de casos de uso e justificativa de escopo
- `src/`: código-fonte do programa standalone inicial

## Como executar

```bash
javac -d out src/Main.java
java -cp out Main
```
